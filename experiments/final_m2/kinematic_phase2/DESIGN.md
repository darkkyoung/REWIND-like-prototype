# 결과 계산 전 고정한 Phase 2 설계

Train300 anchor GT의 연결별 중앙값 L을 사용한다. 개인별 길이 식별은 미확인이다. Control 좌표를 길이와 방향으로 분해하고 길이 오차가 5%를 넘을 때만 초과분을 보정한다. 수정량은 L의 12% 이내다. 관절의 양안 좌표 가용성 및 정규화 xy 등속 외삽 오차(32px 척도)가 크면 보정 gain을 0.35에서 최대 0.8까지 높인다. 직전 수정량을 25% 반영해 보정량 변화를 제한한다. 자세나 방향을 시간 평균하지 않는다. 부모 변화는 연결된 자손으로 전달한다. 골반 고정. gap/sequence 변경 시 history 초기화. 비교 EMA는 현재 0.75, 직전 출력 0.25.

Oracle JPE/RR은 각각 독립 최솟값, DP는 프레임 JPE 합 + 인접 FDE 합 + 전환당 0.25 raw를 최소화한다. 모두 사후 분석 전용이다. 성공 기준은 15개 각 조건에서 Control보다 RR JPE 및 Bone Distortion 감소, FDE 비악화로 고정한다. 조건별 결과와 전체 통과 수를 보고한다. 정책을 결과에 맞춰 다시 조정하지 않는다.

오탐률은 Phase 1처럼 비오염 프레임 중 보정 적용 비율로 정의한다. 함께 기록하는 harmful rate는 보정 후 실제 JPE가 악화된 비율이다. fast는 기존 평가용 라벨을 따른다. 각 조건 전환 프레임은 기존 gate 전환 시점으로 고정해 정책별 FDE를 같은 프레임에서 비교한다.
